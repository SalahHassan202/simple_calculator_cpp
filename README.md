# 🚀 simple_calculator_cpp

## 🚀 About This Repository:
This repository contains the code for a simple calculator built using C++. The calculator allows the user to perform basic arithmetic operations like addition, subtraction, multiplication, and division. The user inputs two numbers and an operator, and the program returns the result of the chosen operation.
